# Dependencies

The Skill has no mandatory executable dependency.

## Optional warning layer

`content-compliance-checker` may be used as a high-recall warning layer when it
is installed and available to the current agent. It is not bundled with this
package, and this package makes no claim about its license or provenance.

If it is unavailable, continue with the deterministic review categories and
evidence-boundary workflow in `SKILL.md`. Record that the optional detector was
not run. Never treat detector output as an official platform decision.
