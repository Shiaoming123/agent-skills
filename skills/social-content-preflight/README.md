# Social Content Preflight

Version 0.1.1

An Agent Skill for reviewing Chinese social-media drafts before publication.
It checks hard risks, evidence boundaries, privacy and copyright, audience fit,
platform adaptation, and the final human-confirmation gate.

## Privacy-safe distribution

This public package contains only a generic account-profile template. Copy
`references/account-profile-template.md` into private project context and fill
it there; do not commit personal, employer, customer, or unreleased information
to a public Skill package.

## Dependencies

There are no mandatory executable dependencies. See `DEPENDENCIES.md` for the
optional `content-compliance-checker` warning layer and its fallback behavior.

## Policy scope

The platform links in `references/platform-rules.md` are starting points and
may become outdated. Recheck official rules for commercially sensitive,
controversial, or boundary-adjacent content. This Skill cannot guarantee
approval, reach, or legal compliance.
