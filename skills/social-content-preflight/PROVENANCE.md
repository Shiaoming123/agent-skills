# Provenance

Version: 0.1.0

This package is an original workflow by Shiaoming123 for reviewing Chinese
social-media content before publication. It combines factual-boundary checks,
privacy and copyright review, account-fit review, platform adaptation, and an
explicit human-confirmation gate.

The package links to public platform rules but does not bundle platform policy
text or claim affiliation with Xiaohongshu, Douyin, or Bilibili. Platform rules
change over time; the linked sources and their recorded research date are a
starting point, not a permanent or exhaustive policy statement.

The original private account profile and agent-specific interface metadata are
not included. This release contains a generic account-profile template and
synthetic example only.

tag evidence for this exact package is available in the local repository as the
annotated tag `v0.1.0`.
