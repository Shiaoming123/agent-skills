# 在现有项目中使用

## 与设计治理配合

若可用，先复用 `agent-design-system-builder` 的 LOCKED / EXISTING / EXPLORE 分类。参考已确认时按 LOCKED 实施；只有风格偏好时，把这套配方映射到产品已有内容，不复制演示业务。

Figma 是可选实现载体：已有文件和编辑权限时，优先将 Surface / Media / Header / Stat / Action 等组件和对应变量落入同一规范；多团队目标未明确时，不任意写入其他团队。没有可用 Figma 时，使用本地 Design Contract 和 token 继续完成已授权工作，不把连接 Figma 当成通用阻塞门槛。

## 技术栈映射

| 环境 | 推荐落点 |
| --- | --- |
| 原生 HTML/CSS/JS | 参考示例的 `.morph-surface`、`.layer` 和 `switchCard()` |
| React | Surface 固定存在，内容以稳定 key 管理；在 layout effect 中测量，卸载清理；优先复用已安装的布局/退出动画能力 |
| Vue | 通过 ref 测量当前层；需要 DOM 更新后测量时等待 nextTick；离开钩子清理旧层并恢复焦点 |
| 现有组件库 | 复用 Button、Dialog、Tooltip 等语义原语，通过 token 和 variant 定制外观 |

不要仅为模仿一个动画更换路由、状态管理或全项目 UI 框架。若选用库，查当前官方 API；本 Skill 不固定依赖版本。

## 将示例改成真实产品

1. 拷贝所需组件或 token，不整包覆盖现有项目。
2. 将示例文字、人物图片、活动数据换成产品内容；把静图播放与近似草地运动替换为真实媒体/渲染实现（如需要）。
3. 将搜索、便签保存、方向导航接到真实数据。方向按钮需要地址；没有地址的示例提示不算导航功能。
4. 用组件 state 与受控输入替换示例中适合原生演示的 innerHTML 模板；所有不可信文本通过文本节点或框架转义渲染。
5. 默认移除 Gallery/Morph 控制条、网格、玻璃光标。这些是为了观察效果而增加的工具。
6. 映射新 token 到现有命名；不要让 example 的全局 `button` 或 `body` 样式污染整站。

## 素材与环境

示例图片来自本次用户提供的第三方演示截图，保留在 `assets/example/assets/` 以记录复刻结果，具体来源见 PROVENANCE。它们不是通用商业素材包。其他产品默认换成用户拥有或获得许可的图片。

示例不依赖在线 API、远程字体或构建工具。不要带入原 Sites 的部署配置、项目标识、凭据、下载的完整视频或临时文件。不要把运行本 Skill 等同于授权发布网站或推送仓库；外部写入按当前用户指令执行。
