# 案例：Soft Surfaces 组件复刻

## 参考和交付

用户提供了一张 2048 × 944 的截图，以及 [Marvin Schwaibold 的演示视频](https://x.com/MSchwaibold/status/2096059496812716307/video/1)。原帖视频约 27.55 秒；通过分时接触表和局部帧观察，识别到画廊、单表面状态切换、并排网格与高度/圆角读数。

本次的复刻代码已整理在 assets/example 中。它是根据视觉观察独立编写的代码，不是原作者源码，也没有把原视频嵌入页面冒充实现。

## 三个决定性观察

1. **边界很轻，但布局不松散。** 三列同宽、较大的行列间隔、卡片内部一致的 padding 共同建立秩序。卡片高度随内容不同，不强行铺成同高方块。
2. **内容比容器更有色彩。** 白底、深灰字、少量蓝色状态，照片成为主要颜色来源。便签衬线与数字字号形成层级，不靠每卡一个彩色标题。
3. **外壳和内容分开运动。** 短卡片变成长卡片时，外壳仍是同一个物体；内容分层退出/进入，网格揭示几何变化。不能简单用两个完整组件的 opacity 交叉替换来代替。

## 本次实施决策

| 决策 | 原因 |
| --- | --- |
| 原生 HTML/CSS/JS | 本次是独立组件研究，避免为七个展示组件引入完整应用架构 |
| 共用外壳 + 绝对定位内容层 | 允许自然测量与连续高度过渡，文字不跟随外壳缩放 |
| WAAPI 控制内容，CSS 控制外壳 | 生命周期与几何参数分别管理，仍共用时间基准 |
| 截图局部裁图 | 保留人物、花朵、包装等参考特征，不用无关图库替换 |
| 研究模式额外提供播放/慢速/网格 | 使用户能主动观察视频中的效果，画廊布局保持克制 |
| Figma 未创建新文件 | 账户可识别，但多个团队只有 View 信息且目标未选定；没有声称已完成 Figma 原型 |

## 复用时的改进重点

原演示已经足以表达风格，不能据此声称生产就绪。生产移植优先验证快速打断时的当前动画取样、离场层 inert、焦点恢复、ResizeObserver 测量、低性能设备上的 blur 成本和 reduced-motion。原图里的低对比小字也应按实际产品可读性调整。

本 Skill 的价值在于把参考、参数、架构与验证边界一起保留下来，而不是把一次环境限制或某个演示数据变成所有项目的强制规则。
