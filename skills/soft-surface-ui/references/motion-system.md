# 连续表面变形的实现配方

## 1. 把动效拆为四个独立层

| 层 | 改变什么 | 不承担什么 |
| --- | --- | --- |
| 外壳 surface | 高度、需要时的宽度、底色、边框、圆角 | 不整体缩放正文 |
| 旧内容 outgoing | 透明度、小幅位移、轻微模糊 | 不继续接收点击或焦点 |
| 新内容 incoming | 透明度、小幅位移、轻微模糊 | 不突然撑开外壳 |
| 可选观察器 mesh | 同步的实际高度与圆角 | 不参与产品业务布局 |

视频呈现的是同一容器在不同内容之间连续变化。外壳稳定存在，新旧内容短暂重叠，但应只有一个可交互的当前状态。

## 2. 参数与节奏

示例是人工调校的近似值，没有原作者的源代码或完整时间曲线。

| 动作 | 起始配方 |
| --- | --- |
| 悬浮 / 按压 | 180–250ms，悬浮上移约 3px，按压 scale(.992) |
| 外壳高度与颜色 | 700ms，`cubic-bezier(.22,1,.36,1)` |
| 旧内容退出 | 总时长的 52%，opacity 1 → 0，Y 0 → -6px，blur 0 → 5px |
| 新内容进入 | 延迟总时长的 16%，持续 80%，opacity 0 → 1，Y 9px → 0，blur 7px → 0 |
| 慢动作 | 将持续时间和延迟同时 ×2，不改变距离 |
| 自动研究播放 | 每 2700ms 切换；慢速每 4300ms 切换 |

初次渲染可以关闭过渡，避免从 0px 拉出整个页面。生产环境可把 blur 降到 2–4px 或去掉：大图片模糊的成本高，而且可能显得发虚。

## 3. DOM 与尺寸测量

```html
<div class="surface">
  <div class="content-layer"><!-- 当前内容 --></div>
</div>
```

```css
.surface {
  position: relative;
  overflow: hidden;
  border-radius: var(--ss-radius-card);
  transition:
    height var(--ss-motion-surface) var(--ss-ease),
    background-color var(--ss-motion-surface) var(--ss-ease);
}
.content-layer {
  position: absolute;
  inset: 0 auto auto 0;
  width: 100%;
}
```

宽度确定后，先插入新层，以 `getBoundingClientRect().height` 测量其自然高度，再把这个像素值写入外壳。绝对定位使内容不会直接推动父容器。不要指望一般 CSS `height: auto` 过渡在所有目标浏览器中工作。

示例对应 `assets/example/app.js` 的 `switchCard()`：构建新层 → 测量 → 改外壳和网格高度 → 分别播放退场、入场 → 清理旧层 → 更新状态标签。

如果把新层设为 `inset: 0`，同时锁定 top/bottom，可能测到父容器的旧高度而非内容自然高度。保留自然块高度。字体、图片和异步内容会改变测量结果；可用 `ResizeObserver` 观察**当前内容层**，按变化重定向外壳高度，不观察并反写同一个外壳造成循环。

## 4. 快速打断与清理

这是从演示迁移到真实组件时最需要强化的部分：

1. 以目标状态 ID 或递增 generation 标记当前切换。
2. 打断前读取当前 opacity/transform；先读再取消旧动画，否则取消会恢复底层样式，引起闪白。
3. 旧层立即设为 `inert`，必要时加 `aria-hidden="true"`，并禁用 pointer events。先把其中的焦点移到稳定且合理的控件。
4. 只保留当前入场层与必要的退场层；快速连点不能积累无限 DOM 或动画。
5. 退出动画完成或被取消均清理对应旧层；取消 Promise 要处理 rejection。
6. 异步回调写状态前检查 generation，旧动画不能覆盖新状态。
7. 卸载时断开 ResizeObserver、清理播放计时器、取消 RAF 和残留动画。

不要把所有动画的取消都解释为错误，也不要取消时重新绘制整个页面。状态频繁更新的输入框不应在每一帧或每次敲键时重建。

## 5. 画廊进入研究态

可以使用 FLIP：读取原卡片与目标容器的矩形差，短暂从原位置过渡到目标位置。研究态外壳变化时仍保持文字自然排版。若短暂缩放导致文字明显失真，改为只移动容器并独立淡入目标内容。

使用 `<dialog>.showModal()` 时，背景自动 inert。研究态所需的控制条应位于 dialog 内，否则可能看得见却点不到；关闭后恢复合理焦点。示例把 toolbar 移入/移出 dialog，但真实应用也可用本身就在 modal 内的控件。

## 6. 网格观察器

用 CSS repeating/linear gradients 或 SVG 画精确网格即可，无需生图。与卡片外壳共用时长、缓动和目标高度。数字读数若代表“当前高度”，用 RAF 读实际矩形；若只是“目标高度”，清楚标注，不混用。圆角也同理：本次示例是固定 24px，不应宣称其圆角会动态变化。

它是可选开发/研究视图，真实业务产品通常不需要。窄屏空间不足时隐藏或换为可展开面板，不挤压卡片。

## 7. 性能与无障碍

- 小型孤立卡片改变 height 的布局成本通常可控；大列表或复杂表格先测性能，再考虑布局动画库或 FLIP。
- 优先动画 transform/opacity，限制 blur 面积。不要对全屏长期使用高强度 backdrop-filter。
- `prefers-reduced-motion` 下关闭自动运动、缩短/移除位移模糊，并保证内容仍能立即切换。
- 自动轮播是用户启动的演示功能；页面不可见时停止。普通产品不默认循环改变正在阅读的内容。
- 若控件是播放静图动画，不用“视频已播放”之类文字。计时器、音频和视频的状态应有真实的数据来源。
