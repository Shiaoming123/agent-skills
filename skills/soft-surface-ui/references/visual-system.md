# 视觉系统：从截图到可执行规范

## 1. 视觉主张

用足够的留白、清楚的排版和极轻的边界，使信息像独立但属于同一体系的物件。它接近极简卡片式工具界面：没有大面积毛玻璃，没有明显的新拟态凹凸，不依靠彩色背景或厚重投影建立层级。

## 2. 本次测量与实现参数

以下为截图的近似测量及示例采用的值，不是原作者公开的设计 token。截图为 2048 × 944，左右录屏区域不属于页面。截图中的白色区域约 1420px 宽，组件区域约 988px 宽。

| 对象 | 示例值 | 用途与调整边界 |
| --- | --- | --- |
| 页面 / 卡片 | `#ffffff` | 保持真白，不自动改成奶油色或灰白 |
| 主文字 | `#27272a` | 标题、数值、重要内容 |
| 次文字 | `#89888e` | 示例中的说明与元数据；真实产品检查对比度 |
| 卡片边界 | `#ecebef`，1px | 轻微但可见的边界，不叠加多个相近外框 |
| 强调蓝 | `#229dcc` | 活动图表的选中柱 |
| 未读蓝 | `#169fc1` | 7px 未读状态点，不作为无含义的装饰 |
| 弱数据蓝 | `#d8e8f1` | 未选中的活动柱 |
| 便签底色 | `#fff2a9` | 仅用于短状态标签 |
| 卡片圆角 | 24px | 嵌套组件不必都用同样圆角 |
| 图片圆角 | 7–8px | 与卡片形成内外层级 |
| 卡片内边距 | 20px；放大研究态 24px | 单个状态内部保持一致 |
| 列宽 / 列间距 | 约 302px / 40px | `988 = 302 × 3 + 40 × 2` |
| 行间距 | 48px | 按每行最高卡片形成下一行起点，不是瀑布流 |
| 默认微阴影 | `0 3px 4px #25233002, 0 8px 16px -12px #2823330b` | 极弱环境阴影 |
| 悬浮阴影 | `0 12px 28px -14px #33324724` | 配合上移 3px，避免发亮或重黑阴影 |

迁移到真实业务页面时，`#89888e` 在白底上的小字号对比度可能不足；可用 `#6f6e75` 等更深的次文字，实际测量后在契约中记录这一偏差。状态还应由文字、形状或选中语义表达。

## 3. 字体层级

| 用途 | 示例 | 约束 |
| --- | --- | --- |
| UI 字体 | Arial / Helvetica / sans-serif | 可替换为项目已有系统字体，避免无必要加载远程字体 |
| 卡片标题 | 14px，500 | 字重克制，避免整页粗黑 |
| 说明文字 | 13px，1.5–1.55 行高 | 参考密度；真实产品可按可读性提升到 14–16px |
| 外侧标签 | 12px | 低强调的组件名称 |
| 小元数据 | 10–11px | 仅忠实研究态沿用，业务 UI 不机械复制 |
| 便签引用 | Georgia，24px，约 1.12 行高 | 衬线只承担这一个特殊文本角色 |
| 研究态引用 | 28px | 是明确设计状态，不通过变形动画不断拉伸文字 |
| 时间 / 距离 | 44px | 单位降为 12px，与大数值对齐 |

中文迁移：使用系统中文无衬线字体，便签可选设备已有的宋体/衬线字体。重新测量换行与行高，不按英文负字距生搬；不要静默下载未知许可的字体。

## 4. 卡片结构

- **Inbox**：标题/未读数/搜索 → 三条消息 → 时间与参考缩略图。只给未读消息加点。
- **Quick note**：UI 标题 → 两三行衬线文本 → 底部短标签；不把正文垂直居中。
- **Mood board**：2 × 2 图片矩阵 → 标题与描述 → 右侧引用数量。
- **Up next**：标题和时钟图标 → 大时间与小单位 → 事件名称/说明 → 头像与方向按钮。
- **Nike running**：满幅媒体 → 底部可读文字和播放控件。只在媒体底部放必要的渐变遮罩。
- **Activity**：标题和图标 → 距离 → 七根简洁柱形。不增加坐标轴、复杂图例或背景网格。
- **Shader Experiments**：左侧高图，右侧两张小图 → 信息页脚。
- **Focus**：视频研究态额外示例；暗色表面、环形刻度、计时文本和小型按钮。它是明确的局部深色变体。

## 5. 响应式与图片

桌面三列，中等宽度两列，窄屏单列，维持 DOM 的阅读顺序。列数断点可根据内容实际宽度调整；示例是 800px 和 640px。预留 20–24px 窄屏边距，避免容器固定 302px 导致横向滚动。

图片使用确定宽高或 aspect-ratio，提前占位；延迟加载不应突然改变形变终点。对比参考检查 `object-fit` 与 `object-position`，尤其是跑步人物与花朵。不要把截图里已有的文字/按钮一起裁入图片后又绘制一遍。

## 6. 避免视觉漂移

避免新增营销头图、导航侧栏、彩色渐变画布、霓虹边框、重磨砂、超大圆角药丸容器、每张卡片各一套阴影。没有用户要求时，也不加弹跳旋转、3D 翻转或循环漂浮。
