# 本次示例

## 运行

直接打开 `assets/example/index.html`，或从 Skill 根目录运行：

```bash
python -m http.server 8080 --bind 127.0.0.1 --directory assets/example
```

然后访问 `http://127.0.0.1:8080`。停止服务用 Ctrl+C。示例是静态页面，没有 npm 安装、后端服务或账户要求；本地便签保存依赖浏览器允许 localStorage。

## 交互

| 操作 | 结果 |
| --- | --- |
| 点击卡片空白区域 / 聚焦卡片后 Enter | 从画廊进入 Morph 研究态 |
| 左右箭头 / 圆点 | 手动切换八个状态 |
| 播放按钮 | 自动轮播，再次点击暂停 |
| `1×` | 切换到 `0.5×` |
| 网格按钮 | 桌面并排显示同步变形网格；窄屏不显示 |
| Gallery / 关闭 / Escape | 返回七卡片画廊 |
| Inbox 搜索 | 在本地示例消息中筛选，包括无结果状态 |
| Quick note 的 Edit / Done | 编辑并尝试在当前浏览器保存 |
| 图片 | 放大当前参考并返回集合 |
| Activity 柱形 | 改变选中的演示日期和距离 |
| Focus | 计时、暂停、复位（研究态额外状态） |

## 文件映射

| 文件 | 内容 |
| --- | --- |
| `assets/example/index.html` | 画廊入口、研究态 dialog、控制条 |
| `assets/example/style.css` | 完整样式、断点、分层动效、网格与媒体近似 |
| `assets/example/app.js` | 八状态模板、切换、播放、搜索、便签、选中与焦点恢复 |
| `assets/example/assets/*.webp` | 从原截图提取的九个参考素材 |
| `assets/primitives/tokens.css` | 可独立映射到其他项目的样式与动效变量 |

## 已知近似与边界

- 本例复刻截图中的七张卡片，并从视频加入 Focus 状态；未复刻视频里所有音乐、航班、天气等组件。
- 跑步是静图的缓慢移动/缩放，不是原视频；草地是图片变形，不是原作者的 shader。
- 原截图素材尺寸较小，放大时清晰度有限；没有进行 AI 补绘并假装是原图。
- 方向按钮没有真实餐厅地址，只说明演示数据的限制。
- 圆角固定为 24px；主要连续变化的是高度、底色与内容。网格也是观察器，不是真实有限元/物理形变。
- 示例是便于阅读和试验的原生实现；移植到应用时按 integration.md 加强组件封装、状态管理和测量生命周期。
